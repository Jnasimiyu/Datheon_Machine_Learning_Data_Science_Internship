# Datheon Machine Learning & Data Science Internship

## About
This repository contains projects completed as part of the Datheon Machine Learning and Data Science Internship.

## Projects

### Task 1: Supervised Classification
- Dataset: Iris
- Models: Logistic Regression and Decision Tree
- Evaluation: Accuracy, Precision, Recall and F1-score
- Visualisations: Pairplot and Confusion Matrix

### Task 2: California Housing Price Prediction
- Dataset: California Housing
- Models: Ordinary Least Squares (OLS), Ridge and Lasso Regression
- Techniques: Feature Engineering, Missing Value Imputation, Standardisation, One-Hot Encoding and GridSearchCV
- Evaluation: RMSE, MAE and R²
- Visualisations: Correlation Heatmap, Predicted vs Actual and Residual Distributions

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
